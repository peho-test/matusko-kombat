# MATÚŠKO KOMBAT XII

Narodeninová bojovka v štýle Mortal Kombat II pre Matúška (12) a Šimona.

**Hraj:** https://peho-test.github.io/matusko-kombat/

- Počítač: klávesnica pre 2 hráčov alebo ovládače PlayStation (Chrome/Edge).
- Mobil: otvor odkaz v prehliadači, otoč na šírku, cez „Pridať na plochu“ bude ako appka a pôjde aj offline.
- Zvuk sa zapne po prvom ťuknutí / kliknutí / klávese.

Grafika a zvuky sú vytvorené pomocou AI (Higgsfield, ElevenLabs), hudba je z pesničiek od ujka Peťa.
